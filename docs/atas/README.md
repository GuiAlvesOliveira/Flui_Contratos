# Atas de reunião e de sprint (DOC-02)

Uma ata por sprint (planejamento, revisão ou reunião de orientação), com **decisões, responsáveis e pendências**. Nome do arquivo: `sprint-<n>-<aaaa-mm-dd>.md`, a partir do [modelo](TEMPLATE.md).

As atas registram o que foi combinado na reunião. Este repositório não inventa atas: cada uma é escrita por quem participou, no dia da reunião ou logo depois.
